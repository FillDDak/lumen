# LUMEN — 빛의 악기

백만 개의 빛 입자로 연주하는 인터랙티브 오디오비주얼 악기.
빌드 도구도, 외부 라이브러리도 필요 없고, 로컬에서는 인터넷 연결 없이도 돌아갑니다.

**▶ 링크: https://fillddak.github.io/lumen/**

## 실행

위 주소로 접속하면 PC와 모바일 어디서든 바로 열 수 있습니다. 웹캠 거울과 마이크는 https 주소에서만 작동하므로, 휴대폰에서는 이 주소로 여세요.

로컬에서는 `index.html`을 더블클릭해 Chrome이나 Edge로 열면 됩니다.

> 로컬 서버로 띄우고 싶다면 `npx serve .` 또는 `python -m http.server`를 쓰면 됩니다.

| 동작 | 결과 |

| 녹화 | 영상과 소리를 함께 저장합니다 (브라우저에 따라 `.webm` 또는 `.mp4`) |

## 여덟 가지 형태

성운 · 은하 · 고리 행성 · 날갯짓하는 나비 · 로렌츠 끌개 · DNA 이중나선 · 토러스 매듭 · 음악에 맞춰 뛰는 심장

**로렌츠 끌개**는 미리 그려둔 모양이 아닙니다. 모든 입자가 실제 로렌츠 방정식을 따라 흐르면서 스스로 나비 모양의 끌개로 모여듭니다. 그 옆의 **나비**는 "나비효과"라는 이름이 붙은 바로 그 현상에 대한 오마주입니다.

처음 화면에서는 LUMEN 글자 뒤로 빛 입자들이 모여 파비콘과 같은 **빛의 구**를 이룹니다.

## 설정

입자 수(6.5만 ~ 209만 개), **프레임 제한**(모니터 주사율 · 30 · 60 · 120 fps), 잔상, 빛 번짐, 밝기, 입자 크기, 난류, **소리 반응**(음악에 맞춰 빛이 일렁이는 세기, 0%면 반응하지 않음), 음량, 카메라 자동 회전을 조절할 수 있습니다. 설정은 브라우저에 저장됩니다.

> 기본값 '자동'은 모니터가 화면을 새로 그릴 때마다 한 번씩 그려서, 브라우저가 보여줄 수 있는 최대치로 동작합니다. 30 fps는 노트북 배터리와 발열을 줄일 때 유용합니다.

## 모바일 참고

- 느린 기기에서는 입자 수를 자동으로 줄입니다.
- 아이폰은 무음 모드에서도 소리가 납니다. 대신 LUMEN 소리를 켜거나 마이크를 쓰면, iOS 특성상 다른 앱(음악 앱 등)의 재생이 멈춥니다.

## 어떻게 만들었나

- **GPU 시뮬레이션** — 입자 상태(위치, 속도)는 RGBA32F 텍스처 두 장에 저장되고, 매 프레임 프래그먼트 셰이더 한 번(MRT)으로 모든 입자를 동시에 적분합니다. 1,048,576개 기준, 노트북 내장 GPU(Intel Arc)에서도 모니터 주사율을 여유 있게 따라갑니다.
- **힘** — 목표 형태로 당기는 스프링, 해석적 기울기를 쓴 심플렉스 노이즈 기반 컬 노이즈 난류, 포인터 광선 주위의 소용돌이, 블랙홀 중력, 구면으로 퍼지는 충격파 8개, 음악의 저음에 맞춘 호흡.
- **렌더링** — 가산 혼합 포인트 스프라이트를 HDR(RGBA16F) 버퍼에 그리고 → 잔상 → 듀얼 필터 블룸 → ACES 톤매핑, 비네팅, 색수차, 필름 그레인.
- **소리** — 샘플 파일 없이 Web Audio API로 실시간 합성합니다. 디튠한 톱니파 패드의 코드 진행(Dmaj9 → Bm11 → Gmaj7♯11 → A), D 펜타토닉 FM 벨 멜로디, 서브 베이스, 컨볼루션 리버브와 딜레이. 멜로디의 음 하나하나가 빛의 파문으로 보입니다.
- **형태 생성** — 무거운 기하 생성은 Blob URL로 만든 Web Worker에서 돌아가므로 형태가 바뀌어도 화면이 멈추지 않습니다.
- **아이콘** — 파비콘과 홈 화면 아이콘은 LUMEN이 실제로 렌더링한 빛 입자 구를 촬영해 만들었습니다.

## 파일 구성

```
index.html            마크업, 아이콘 스프라이트
css/style.css         UI 스타일
js/math.js            벡터·행렬
js/gl.js              WebGL2 헬퍼
js/shaders.js         시뮬레이션·렌더·후처리 GLSL
js/shapes.js          형태 생성기 + 워커
js/audio.js           생성 음악 엔진
js/engine.js          GPU 파이프라인
js/app.js             입력, 카메라, UI, 자동 여행
favicon-32.png        탭 아이콘
icon-192.png          안드로이드 아이콘
icon-512.png          재생 제어 화면용 이미지
apple-touch-icon.png  아이폰 홈 화면 아이콘
```

URL 파라미터: `?n=512`는 입자 텍스처 크기를 지정하고(512² = 262,144개), `?autostart`는 인트로를 건너뜁니다.

요구 사항: WebGL2와 `EXT_color_buffer_float`를 지원하는 브라우저 (최신 Chrome, Edge, Firefox, Safari).
