# LUMEN — 빛의 악기

백만 개의 빛 입자로 연주하는 인터랙티브 오디오비주얼 악기.
빌드 도구도, 외부 라이브러리도, 인터넷 연결도 필요 없습니다.

## 실행

`index.html`을 더블클릭해 Chrome이나 Edge로 여세요. 그게 전부입니다.

> 로컬 서버로 띄우고 싶다면 `npx serve .` 또는 `python -m http.server`를 쓰면 됩니다.

## 해볼 것들

| 동작 | 결과 |
| --- | --- |
| 커서로 휘젓기 | 빛에 물결이 일고, 빠르게 그으면 음이 울립니다 (화면이 하프가 됩니다) |
| 클릭 | 한 음과 함께 작은 파동이 퍼집니다 |
| **길게 누르기 → 놓기** | 블랙홀이 빛을 빨아들이고, 놓으면 초신성처럼 터집니다 |
| 오른쪽 드래그 / 휠 | 카메라 회전 / 확대 |
| 사진을 화면에 끌어놓기 (또는 붙여넣기) | 사진이 백만 개의 빛으로 다시 그려집니다 — 밝기가 입체 부조가 됩니다 |
| 글자 | 한글·영어·이모지 무엇이든 빛으로 씁니다 (`/`로 줄바꿈) |
| 거울 | 웹캠에 비친 당신이 실시간으로 빛 입자가 됩니다 |
| 마이크 | 목소리나 음악에 맞춰 빛이 반응합니다 |
| 녹화 | 영상과 소리를 함께 `.webm`으로 저장합니다 |

단축키: `1–8` 형태 · `Space` 대폭발 · `T` 글자 · `I` 사진 · `C` 거울 · `A` 자동 여행 · `M` 소리 · `H` UI 숨기기 · `P` 스크린샷 · `R` 녹화 · `F` 전체 화면

## 여덟 가지 형태

성운 · 은하 · 고리 행성 · 날갯짓하는 나비 · 로렌츠 끌개 · DNA 이중나선 · 토러스 매듭 · 음악에 맞춰 뛰는 심장

**로렌츠 끌개**는 미리 그려둔 모양이 아닙니다. 모든 입자가 실제 로렌츠 방정식을 따라 흐르면서 스스로 나비 모양의 끌개로 모여듭니다. 그 옆의 **나비**는 "나비효과"라는 이름이 붙은 바로 그 현상에 대한 오마주입니다.

## 어떻게 만들었나

- **GPU 시뮬레이션** — 입자 상태(위치, 속도)는 RGBA32F 텍스처 두 장에 저장되고, 매 프레임 프래그먼트 셰이더 한 번(MRT)으로 모든 입자를 동시에 적분합니다. 1,048,576개 기준, 노트북 내장 GPU(Intel Arc)에서 약 144 fps가 나옵니다.
- **힘** — 목표 형태로 당기는 스프링, 해석적 기울기를 쓴 심플렉스 노이즈 기반 컬 노이즈 난류, 포인터 광선 주위의 소용돌이, 블랙홀 중력, 구면으로 퍼지는 충격파 8개, 음악의 저음에 맞춘 호흡.
- **렌더링** — 가산 혼합 포인트 스프라이트를 HDR(RGBA16F) 버퍼에 그리고 → 잔상 → 듀얼 필터 블룸 → ACES 톤매핑, 비네팅, 색수차, 필름 그레인.
- **소리** — 샘플 파일 없이 Web Audio API로 실시간 합성합니다. 디튠한 톱니파 패드의 코드 진행(Dmaj9 → Bm11 → Gmaj7♯11 → A), D 펜타토닉 FM 벨 멜로디, 서브 베이스, 컨볼루션 리버브와 딜레이. 멜로디의 음 하나하나가 빛의 파문으로 보입니다.
- **형태 생성** — 무거운 기하 생성은 Blob URL로 만든 Web Worker에서 돌아가므로 형태가 바뀌어도 화면이 멈추지 않습니다.
- 느린 기기에서는 입자 수를 자동으로 줄입니다. 설정에서 6.5만 ~ 209만 개 사이로 바꿀 수 있습니다.

## 파일 구성

```
index.html        마크업, 아이콘 스프라이트
css/style.css     UI 스타일
js/math.js        벡터·행렬
js/gl.js          WebGL2 헬퍼
js/shaders.js     시뮬레이션·렌더·후처리 GLSL
js/shapes.js      형태 생성기 + 워커
js/audio.js       생성 음악 엔진
js/engine.js      GPU 파이프라인
js/app.js         입력, 카메라, UI, 자동 여행
```

URL 파라미터: `?n=512`는 입자 텍스처 크기를 지정하고(512² = 262,144개), `?autostart`는 인트로를 건너뜁니다.

요구 사항: WebGL2와 `EXT_color_buffer_float`를 지원하는 브라우저 (최신 Chrome, Edge, Firefox, Safari).
